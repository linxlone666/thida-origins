# Reconstructed version history

This repository was imported from saved project snapshots and release artifacts at the owner's request. These are **reconstruction commits**, not the original development commits. Commit dates record the import. Authorship of the imports is `linxlone666`, using the account's GitHub noreply address.

The archive covers **29 released versions (0.1.0 through 0.8.9)** and one additional Forge passive working snapshot. **14 source snapshots** survived, including that working snapshot. All 29 original release JARs are preserved with SHA-256 checksums.

## What the tags mean

- `v...`: a recovered source snapshot for that version. See its provenance file; archived JARs were not rebuilt to claim reproducible correspondence.
- `archive/v...`: the release JAR and notes survived, but its source snapshot did not. Source at this tag is still the last recovered source, **not** reconstructed or decompiled source for that binary release.
- `recovered/forge-passives-pre-port`: a working Forge source backup after the original 0.5.5 release. It contains passive changes and must not be mistaken for the original 0.5.5 release's source.

Each `archive/versions/<milestone>/PROVENANCE.json` states the available source, active source snapshot, artifact hash, and limitations. `SOURCE_SHA256SUMS.txt` records every imported source file where available. `SHA256SUMS.txt` records the original JAR bytes. Historical binary archives are intentionally tracked because some source versions are missing; ordinary build outputs remain ignored.
