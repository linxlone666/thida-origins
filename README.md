# ธิดา — Origins สำหรับ Minecraft Forge 1.20.1

ม็อดเสริมพร้อม Origin ธิดา: กำแพงมนต์ พรางตัว เมตตาชาวบ้าน สมุนไพรรักษา หุ่นฟางบัฟ/สาป กาฝากแชร์ดาเมจ พันธะหทัย และโดเมน 30 บล็อก

## ติดตั้ง

1. ใช้ Minecraft Java **1.20.1**, Java **17**, Forge **47.4.0**
2. ติดตั้ง [Origins Forge 1.10.0.9](https://www.curseforge.com/minecraft/mc-mods/origins-forge/files/5314209) (`origins-forge-1.20.1-1.10.0.9-all.jar`) และ [Caelus API 3.2.0](https://www.curseforge.com/minecraft/mc-mods/caelus/files/5281700)
3. ใส่ `thida-origins-1.20.1-0.1.0.jar` ในโฟลเดอร์ `mods` **ทั้งเครื่องผู้เล่นและเซิร์ฟเวอร์**
4. เปิดโลก เลือก Origin **ธิดา** แล้วใช้ `/thida kit` รับไอเทมสกิล หรือคราฟต์ตามสูตรในคู่มือ

Origin และรูปลักษณ์ไอเทมรวมอยู่ใน JAR แล้ว ไม่ต้องติดตั้ง datapack ZIP ซ้ำ หากมีโลกเดิม ใช้ Orb of Origin หรือคำสั่งผู้ดูแล `/origin set <ชื่อผู้เล่น> origins:origin thida:thida`

## เล่นอย่างไร

- คลิกขวาไอเทมเพื่อใช้สกิล; `/thida help` แสดงวิธีควบคุม
- ถือหุ่นนรตราหรือนิลกาลแล้วตีผู้เล่นเพื่อผูกเป้าหมาย จากนั้นคลิกขวาส่งบัฟ/ดีบัฟ
- Shift+คลิกขวาหุ่นเพื่อเปลี่ยนโหมด ถือสองหุ่นคนละมือเพื่อติดสองมาร์คได้ การสลับมือไม่ล้างมาร์ค
- พันธะหทัย: ถือหุ่นพันธะ เล็งผู้เล่นแล้วคลิกขวา
- สมุนไพรฮีลผู้ใช้และเพื่อนร่วม **scoreboard team** เท่านั้น ผู้ดูแลจัดทีมด้วย `/team add allies` และ `/team join allies <ชื่อผู้เล่น>`

อ่านผลของทุกสกิล คูลดาวน์ สูตรคราฟต์ และกติกาพันธะใน [คู่มือพลัง](docs/POWERS.md)

## ค่าเลือดและสมมติฐาน

**2 HP = 1 หัวใจ** ค่า 150 คือเกณฑ์ HP ปัจจุบันสำหรับเริ่มกาฝาก ไม่ใช่เลือดสูงสุด ม็อดไม่เพิ่ม max health ให้เอง

ค่าเริ่มต้นหุ่นกาฝากแตกที่เลือดรวมไม่เกิน 50 HP ดังนั้นผู้เล่น vanilla สองคนที่มีเลือดรวม 40 HP จะเริ่มพันธะกาฝากไม่ได้ ให้ใช้ระบบเพิ่มเลือดของเซิร์ฟเวอร์ หรือปรับ `parasiteBreakHealth` ให้เหมาะสม หากต้องการทดลองตามตัวเลขเดิม ผู้ดูแลตั้ง max health ให้ผู้เล่นทดสอบคนละ 100 HP ได้ตามตัวอย่างในคู่มือ

ค่าใช้งานสร้างใน `<โลก>/serverconfig/thida-server.toml`: ระยะพันธะ 16 บล็อก, ระยะมาร์คทั่วไป 64 บล็อก, โดเมนรัศมี 30 บล็อกนาน 15 วินาที, คูลดาวน์ทั่วไป 20 วินาที และเอฟเฟกต์ทั่วไป 10 วินาที

รุ่นนี้ตีความ **“ตัวหุ่น” เป็นผู้เล่นที่ผูกกับไอเทมหุ่นฟาง** และแชร์ความเสียหาย 50/50 โดยไม่บังคับให้ HP ทั้งคู่เท่ากัน ไอเทมหุ่นใช้ texture vanilla; ยังไม่มี NPC หุ่นหรือโมเดล 3D เฉพาะ

พันธะหทัยช่วยชีวิตหนึ่งครั้งต่อพันธะ ผู้ดูแลถูกล็อกยาแก้สถานะ กาฝาก และโดเมนระหว่างดูแลหัวใจ ระยะเวลา/คูลดาวน์ที่ต้นฉบับไม่ระบุเป็นค่าเริ่มต้นสำหรับทดลองเล่น

## การเชื่อมกับม็อดอื่น

รองรับการรักษาของแอดออนนี้, Instant Health ของ vanilla ที่ระบุผู้ให้ และ Regeneration ที่มีข้อมูลผู้ให้ การรักษาจากม็อดอื่นที่เรียก `heal()` โดยไม่ส่งผู้รักษาไม่สามารถแยกจากการรักษาตนเองได้ ต้องเชื่อมผ่าน `ThidaEvents.addonHeal(caster, target, amount)` พลังที่แก้เลือดตรงด้วย `setHealth()` อาจข้ามเหตุการณ์ของ Forge

## Build และทดสอบ

ตั้ง `JAVA_HOME` เป็น JDK 17 แล้วรัน:

```powershell
./build.ps1
./build.ps1 -Tasks runGameTestServer
```

หรือใช้ `./gradlew build originDatapack` และ `./gradlew runGameTestServer` บนระบบอื่น ต้องมีอินเทอร์เน็ตตอนดาวน์โหลด dependencies ครั้งแรก ผลลัพธ์ JAR อยู่ใน `build/libs` และ ZIP ทรัพยากรอยู่ใน `build/distributions` ZIP นี้ใช้ร่วมกับแอดออนเท่านั้น ไม่ใช่เวอร์ชัน datapack ล้วน

ผลตรวจและข้อจำกัดการทดสอบอยู่ใน [TESTING](docs/TESTING.md)
