# ธิดา 0.6.5 — คำอธิบายไอเทมแบบรายการ

เปลี่ยนคำอธิบายไอเทมทั้งห้าของธิดาจากข้อความยาวเป็นหัวข้อและรายการสั้น ๆ ในเกม:

- สีม่วง: สิทธิ์เผ่ากำเนิดธิดา
- สีฟ้า: วิธีใช้
- สีเขียว: ผลที่ได้รับ
- สีทอง: วิธีควบคุมหรือยกเลิก
- สีเทา: รายละเอียดแต่ละข้อ

นรตราและนิลกาลแสดงข้อมูลหลักก่อน กด Shift ค้างขณะชี้ไอเทมเพื่อดูเงื่อนไขสายสัมพันธ์ ระยะสายสัมพันธ์ และวิธีรับหุ่นเพิ่มเติม ปุ่มปลดสายสัมพันธ์ใช้ `Component.keybind` จึงแสดงตามปุ่มเปิดเมนูหุ่นที่ผู้เล่นตั้งไว้จริง

คำอธิบายยังเป็นภาษาไทยแม้ Minecraft ตั้งเป็นภาษาอื่น ไม่เพิ่มโมเดล เอฟเฟกต์ หรือกฎเกม งานชื่อเล่นเซิร์ฟเวอร์ยังพักไว้ก่อน รวมตัวแก้เข้าโลกรุ่น 0.6.4 ไว้ด้วย

## ไฟล์ที่เปลี่ยนหลัก

- `ThidaTooltips.java`: รูปแบบหัวข้อ สี และรายการข้อความ ใช้ได้ทั้งฝั่งเซิร์ฟเวอร์และ client
- `ThidaMod.java`: ให้ไอเทมใช้รูปแบบรายการ
- `ThidaClient.java`: เพิ่มรายละเอียดขณะกด Shift เฉพาะฝั่ง client
- `assets/thida/lang/th_th.json` และ `en_us.json`: รายการข้อความไทย
- หมายเลขรุ่นและเอกสาร

คอมไพล์และ unit tests เดิม 16 รายการผ่าน รวมการตรวจข้อความภาษาไทยกับ fallback รุ่นนี้ยังไม่ได้ตรวจภาพ tooltip ในเกมด้วยตา การจัดความสูงและความกว้างใช้ระบบ tooltip ของ Minecraft ตามปกติ

ติดตั้งรุ่นเดียวกันทั้ง client/server และปิด Minecraft ก่อนเปิดโปรไฟล์ใหม่ ใช้ JAR ธิดาเพียงรุ่นเดียวในโฟลเดอร์ mods
