# ธิดา 0.6.3 — ข้อความในเกมภาษาไทย

## สิ่งที่เปลี่ยน

- ชื่อเผ่ากำเนิด พลัง ไอเทม คำอธิบาย ข้อความเสียชีวิต และชื่อปุ่มของธิดาเป็นภาษาไทย
- `en_us.json` ใช้ข้อความไทยเหมือน `th_th.json` เพื่อให้ข้อความของแอดออนยังเป็นไทยเมื่อเลือกภาษาอังกฤษหรือภาษาอื่นใน Minecraft ไม่เปลี่ยนภาษาของเกมหรือม็อดอื่น
- ลบข้อความอังกฤษที่แสดงควบคู่ในแจ้งเตือนและคำสั่งช่วยเหลือ แปลข้อความของสกิลเดิมที่ยังเป็นอังกฤษ โดยไม่เปลี่ยนกฎสกิล
- แปลหัวข้อผลตรวจคำสั่งผู้ดูแลและป้ายย่อบนแถบสถานะ
- คงรหัสคำสั่ง เช่น `/thida kit`, `/thidahud` และชื่อปุ่มจริง เช่น R, Esc ให้ใช้ตามเดิม ชื่อผู้เล่นที่เป็นอังกฤษยังแสดงตามชื่อของผู้เล่น
- ไม่เปลี่ยนโมเดล ไอคอน เอฟเฟกต์ ระบบสายสัมพันธ์ หรือมานา และรวมตัวแก้ Advanced Fake Players ของ 0.6.2

## ชื่อผู้เล่นที่เชื่อม

งานรองรับชื่อเล่นเซิร์ฟเวอร์พักไว้ตามคำขอ ชื่อเป้าหมายในเมนูหุ่นและข้อความยังใช้ชื่อบัญชีตามระบบเดิม รุ่นนี้ไม่มีตัวอ่านชื่อเล่นหรือข้อมูลสายสัมพันธ์ใหม่บนไอเทม

## การติดตั้ง

ปิด Minecraft แล้วใช้ `thida-origins-1.21.1-neoforge-0.6.3-neoforge-dev.jar` แทนรุ่นเดิมใน mods ติดตั้งรุ่นเดียวกันทั้ง client/server ใช้ Minecraft 1.21.1 NeoForge และ Java 21 ตามชุดเดิม ไม่ต้องเปลี่ยนการตั้งค่าภาษาของ Minecraft

## การตรวจ

- Unit tests 16 รายการผ่าน รวมการตรวจว่าไฟล์ภาษา fallback ตรงกับภาษาไทย และทุกข้อความมีภาษาไทย
- GameTest 39 รายการผ่านพร้อม Advanced Fake Players 1.0.0 และ Carry On 2.2.4.4 รวมการสร้าง bot และเชื่อม Passive ทั้งสอง
- ตรวจ Singleplayer ด้วยม็อด DRC ทั้งชุดในโฟลเดอร์รันแยก ผ่านถึงหน้า Create World
- ไม่รวม source set สำหรับทดสอบใน JAR ผู้เล่น

ไฟล์ที่เปลี่ยนหลัก: `ThidaMod`, `ThidaEvents`, `ThidaPassives`, `ThidaClient`, `ThidaHud`, `ThidaHudCommands`, `ThidaDebug`, ไฟล์ภาษา, manifest และหมายเลขรุ่น
