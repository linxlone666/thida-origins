# HUD 0.8.3 — ปรับตามภาพของผู้ใช้

แก้เฉพาะการแสดงผลต่อจาก 0.8.2 ไม่เปลี่ยนกติกาสกิล คูลดาวน์ ดาเมจ หรือข้อมูลสายสัมพันธ์

1. HUD สกิลกลับเป็นการ์ดเล็ก: ไอคอน เวลา และหลอดความคืบหน้า ไม่วาดชื่อสกิล คำว่าพัก เลขคาถา หรืออักษรย่อยบนการ์ด ใช้สีและการหรี่ไอคอนแยกช่วงทำงาน/คูลดาวน์เดิม
2. สถานะผู้รับพันธะจัดเป็น grid สองคอลัมน์ ช่องกว้างเท่ากัน ไอคอนตรงกันระหว่างแถว และช่องเวลาวางตำแหน่งร่วมกัน เมื่อเหลือสถานะเดียวจะลดเหลือช่องเดียว ไม่มีการเผื่อแถวที่ไม่มีสถานะ
3. ตำแหน่งอักษรที่ดูเหมือน “ท” ในภาพตรงกับตัวคั่น Unicode `·` ในโค้ด HUD สกิลและคำแนะนำ editor จึงเลิกวาดตัวคั่นนี้ในจุดดังกล่าว ใช้ช่องว่างและ `/` ในคำแนะนำแทน ไม่เปลี่ยนตัวอักษรในชื่อสกิลหรือชื่อผู้เล่น
4. กรอบเลือกและพื้นที่รับเมาส์การ์ดสกิลเปลี่ยนตามขนาดใหม่ ใช้ความสูงเดียวกับการวาดจริง

ไฟล์หลักที่แก้: `ThidaHud`, `ThidaBondHud`, `ThidaHudEditor`, `HudPacking`, ภาษาไทยทั้งสอง locale และเลขรุ่น เพิ่ม unit test ตรวจ grid คอลัมน์ตรงกัน/คืนพื้นที่เมื่อรายการลดลง

คำสั่งตรวจ: `formatJava build runHudPreview -PwithoutIron=true` ด้วย Java 21 ใช้สำเนาโลก `hud-preview` เดิม ตัวอย่างเป็นข้อมูล client สำหรับตรวจภาพ ไม่ส่งคำขอร่ายสกิลหรือสร้างสายสัมพันธ์ เซ็ตภาพและผลตรวจอยู่ในชุดส่งมอบ ไม่มี dependency ใหม่

เอกสาร HUD 0.8.2 เก็บเป็นประวัติ; การจัดการ์ดสกิลแบบมีชื่อและการเรียงผู้รับแบบ flow ในเอกสารนั้นถูกแทนด้วยข้อ 1–2 ของเอกสารนี้
