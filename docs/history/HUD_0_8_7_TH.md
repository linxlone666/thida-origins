# Thida 0.8.7 — สถานะเหนือ hotbar ไม่มีพื้นหลัง

เอาการวาดพื้นหลัง กรอบ และแถบสีข้างแผงผู้รับพันธะเหนือ hotbar ออกใน `ThidaBondHud.drawRecipient` เหลือเฉพาะไอคอน ชื่อสถานะ และเวลา ทั้งขณะเล่นและในตัวอย่าง editor

ยังใช้ grid ตำแหน่ง ขนาด พื้นที่ลาก ฟอนต์ และข้อมูลสถานะเดิม กรอบเลือกแผงในหน้า H ยังแสดงเมื่อเลือกเพื่อให้จัดตำแหน่งได้ ไม่เปลี่ยนพื้นหลัง HUD สายสัมพันธ์หรือการ์ดสกิลส่วนอื่น ไม่เปลี่ยนกติกาสกิลหรือข้อมูลเซฟ

สร้าง JAR ด้วย Gradle task `jar` งานนี้ไม่ได้เพิ่มหรือรัน tests และไม่ได้ตรวจภาพ client รอบใหม่
