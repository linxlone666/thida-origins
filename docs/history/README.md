# บันทึกรุ่นเก่า

โฟลเดอร์นี้เก็บบันทึกการเปลี่ยนแปลง HUD ฟอนต์ inventory และการส่งมอบรุ่นเดิม
เนื้อหาสะท้อนรุ่นที่ระบุในชื่อไฟล์ อาจไม่ตรงกับพฤติกรรมใน branch ปัจจุบัน

ผู้รับงานต่อให้เริ่มจาก [Guide พลังเวทย์](../MAGIC_INTEGRATION_GUIDE_TH.md)
หรือ [Guide เอฟเฟกต์](../EFFECTS_INTEGRATION_GUIDE_TH.md)
และ [โครงสร้างปัจจุบัน](../ARCHITECTURE_TH.md)
ประวัติ release และไฟล์ต้นฉบับยังอยู่ใน `archive/` ที่ราก repository
