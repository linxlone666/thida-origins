# อัลติเรือนเสน่หา

ทดลองบน branch **ultimate-ruen-saneha** จาก main ส่วน **เสน่ห์มายารมณ์** อยู่ที่ branch เดิม **codex/ultimate-mayarom** ใช้ JAR รุ่นเดียวกันทั้ง client และ server ของแต่ละรอบทดสอบ

## วิธีใช้

1. OP ใช้ /thida unlock <player> skill4 กับผู้เล่น Origin ธิดา
2. กดปุ่มสกิล 4 (เปลี่ยนได้ใน Controls) หรือคลิกขวาด้วยยันต์เรือนเสน่หาเดิม เปิดได้โดยไม่เสียมานา
3. กดปุ่มสกิลอีกครั้งเพื่อเปิดเมนู ใช้ลูกกลิ้งและคลิกซ้ายเพื่อเลือกคนในเรือนหรือคนนอก จากนั้นเล็งผู้เล่นแล้วคลิกซ้ายหนึ่งครั้ง ระบบใช้คลิกนั้นเลือกเป้าหมายโดยไม่โจมตี ถ้าจะเปลี่ยนฝ่ายก่อนเลือกเป้าหมายให้กดปุ่มสกิลเปิดเมนูใหม่
4. ยุติจากเมนู หรือคลิกขวาด้วยยันต์อีกครั้ง

โดมยึดจุดชนพื้นใต้ผู้ใช้ตอนเปิด ใช้ระยะสามมิติรัศมี 100 บล็อก อยู่ 5 นาที และเริ่มคูลดาวน์ 20 นาทีเมื่อจบ เวลานับด้วย tick ของโลกหลักขณะที่เซิร์ฟเวอร์เดิน จึงอยู่ต่อเมื่อธิดาตาย ออกเกม หรือข้ามมิติ ไม่เดินระหว่างปิดเซิร์ฟเวอร์

รายชื่อแต่ละฝ่ายมี 5 ช่องและล็อกจนจบ การออกจากโดมไม่คืนช่อง เซิร์ฟเวอร์ตรวจแนวเล็ง ผนัง การล่องหน มิติ และระยะจากจุดศูนย์กลาง การเล็งใช้ระยะที่เซิร์ฟเวอร์ส่งโลกให้ผู้เล่นได้โดยไม่จำกัดด้วยระยะโจมตีประชิด คนนอกมีเฉพาะรายชื่อ และผู้เล่นที่ไม่ได้เลือกเดินผ่านได้ตามปกติ

ธิดาและคนในเรือนรับดาเมจลด 50% ทำดาเมจเพิ่ม 20% และมีความเร็วเทียบเท่า Speed III ในโดม ระบบใช้ตัวปรับความเร็วเพื่อเอาโบนัสออกเมื่อออกจากโดมโดยไม่ลบยา Speed ที่มีอยู่เอง ถ้ามี Speed สูงกว่าอยู่แล้วให้ใช้ค่าที่สูงกว่า ล้างดีบัฟครั้งเดียวตอนธิดาเปิดหรือเมื่อสมาชิกถูกเลือก การกันดีบัฟใหม่มีเวลา 2 นาทีแยกจากเวลาของโดมและนับต่อแม้เดินออก การกลับเข้ามาไม่ล้างดีบัฟหรือรีเวลา คาถานิลกาลที่โดนกันยังใช้ค่าร่ายและคูลดาวน์ตามปกติ ดาเมจที่ถูกแบ่งโดยหุ่นกาฝากใช้ยอดหลังปรับแล้วโดยไม่คูณซ้ำ

## จุดต่อเอฟเฟกต์

ใช้สตรีมเดิมของ ThidaPassiveEffects; ThidaRuenPresentation อ่านข้อมูลกติกาเพื่อส่งภาพโดมและฉายสถานะต่อเนื่อง ฝั่ง client ลงทะเบียน backend และเพิ่ม mapping ตาม [คู่มือเอฟเฟกต์](SKILL_EFFECT_ADAPTER_TH.md) ใน assets/thida/thida_effects/ รุ่นนี้ไม่มี dependency หรือไฟล์เอฟเฟกต์ AAA ใช้ภาพโดมเดิมของม็อด

| Event | จุดยึดและอายุ |
| --- | --- |
| RUEN_DOMAIN_STARTED / RUEN_DOMAIN_ENDED | power ruen_saneha, component domain, WORLD ตำแหน่งพื้นและมิติเดิม, instance เดียวต่อการเปิด |
| RUEN_MEMBER_SELECTED | one-shot ที่ TARGET, spell เป็น inside หรือ outside, activation เดียวกับโดม |
| RUEN_WARD_STARTED / RUEN_WARD_ENDED | component ward ที่ TARGET, instance แยกตามผู้เล่น, ใช้เวลาตามที่ถูกเลือกหรือเปิดอัลติ |

การเข้ามาทีหลังหรือกลับเข้าโดมรับ SYNC สำหรับสถานะที่ยังมีผล ตัว adapter ควรเริ่มเฉพาะภาพต่อเนื่องเมื่อรับ SYNC และหยุดตาม instance ที่ระบุเมื่อได้ STOP

รัน build และ dedicated GameTests ด้วย .\gradlew.bat build runGameTestServer
