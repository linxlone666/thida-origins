# เสน่ห์มายารมณ์ — branch codex/ultimate-mayarom

รุ่นทดลอง `0.9.0-mayarom-dev` ต่อจาก 0.8.9 ทำเฉพาะอัลติแบบกายแท้ ไม่รวมเรือนเสน่หา

## การใช้งาน

- เฉพาะ Origin ธิดา ต้องให้ OP ระดับ 2 ปลดด้วย `/thida unlock <player> skill4`
- ปุ่ม `4` แถวบน เปลี่ยนใน Controls ได้ กดครั้งแรกเปิด กดซ้ำยกเลิก ไม่ใช้มานา
- ใช้ไอคอนเดิมและช่องนับเวลาอัลติเดิมใน HUD ปุ่มอื่นและหน้าปรับ HUD ยังคงเดิม
- ยันต์ `thida:domain_talisman` เดิมคลิกขวาเรียกการเปิด/ยกเลิกเดียวกัน ต้องปลดล็อกเช่นกัน
- ทำงาน 5 นาที จากนั้นคูลดาวน์ 20 นาที กดยกเลิกก่อนครบเริ่มคูลดาวน์ทันที
- ตาย ออกจากเกม หรือย้ายมิติ ไม่ลบอัลติ เวลาเดินต่อด้วยเวลาเกมของเซิร์ฟเวอร์
  เมื่อกลับมาเกิดหรือเข้าเกมจะได้รับผลตามเวลาที่เหลือ ไม่คืนเวลาใหม่
  หากหมดตอนออฟไลน์จะเริ่มคูลดาวน์จากเวลาที่หมดจริง ไม่รอเข้าเกม
- การปิดเซิร์ฟเวอร์พักเวลาเกม สถานะและกำหนดเวลาบันทึกใน SavedData
- อัลติไม่มีจุดศูนย์กลางหรือรัศมี และไม่ใช้โดเมนจุดเดิมของรุ่นเก่า

## ผลกับธิดา

- รับดาเมจน้อยลง 70% โดยคูณดาเมจขาเข้าด้วย 0.30
- ล้างดีบัฟเมื่อเปิด และล้าง/ป้องกันสถานะประเภท HARMFUL ตลอดอัลติ
  รวมดีบัฟภายในของม็อดที่ระบบ cleanse เดิมรู้จัก
  สถานะพิเศษของม็อดอื่นที่ไม่ผ่าน MobEffect หรือระบบเดิมต้องเชื่อมต่อเพิ่มเติม
- โจมตีประชิดสำเร็จทำให้เป้าหมายผู้เล่นลดดาเมจที่สร้าง 20% และตาบอด 10 วินาที
  ตีซ้ำรีระยะเวลา ไม่สะสมเปอร์เซ็นต์จากการตีซ้ำ
- เตรียมสูตร `ดาเมจประชิดเดิม + (พลังเวทย์ × 2)` ไม่มีค่าพลังเวทย์สมมติ
  หากยังไม่ลงตัวเชื่อม ใช้ดาเมจประชิดเดิมตามปกติ อัลติส่วนอื่นทำงานได้

## ผลกับผู้เล่นที่เชื่อมนรตรา

- เมื่อพันธะนรตราทำงานตามเงื่อนไขเดิม เพิ่มดาเมจประชิด 20% และลดดาเมจขาเข้า 20%
- เมื่อผู้เล่นนี้สร้างดาเมจให้ผู้เล่นอื่นสำเร็จ เป้าหมายได้รับผลคาถานิลกาล 2–4 พร้อมกัน:
  - ลดดาเมจที่สร้าง 20% และความเร็วโจมตี 20% เป็นเวลา 10 วินาที
  - เลือดไหล 2 HP/วินาที ไม่ทำให้ตาย และตาบอด 5 วินาที
  - รับดาเมจเพิ่ม 20% เป็นเวลา 10 วินาที
- เป็นผลชั่วคราวเท่านั้น ไม่สร้างพันธะ ไม่เขียนประวัติ ไม่แทนที่เป้าหมายที่เชื่อมอยู่
  ไม่ใช้มานา ไม่ใช้คูลดาวน์คาถา และไม่ลบคาถาปกติที่ใช้อยู่
- ล้างผลเหล่านี้ได้ตามระบบดีบัฟปกติ เป้าหมายที่มีการกันดีบัฟจะไม่รับผล
- การตีซ้ำรีระยะเวลาเลือดไหล แต่ไม่เลื่อนรอบดาเมจทุกวินาทีออกไปเรื่อย ๆ
- หลังอัลติจบ ผลคาถาที่ติดไปแล้วอยู่ตามระยะเวลาของตนเอง แต่ไม่สร้างผลใหม่

## พันธะและการคำนวณ

อัลติใช้งานร่วมกับสกิลอื่นได้ แต่ไม่ข้ามเงื่อนไขของสกิลนั้น:
เป้าหมายหนึ่งคนยังมีพันธะได้ชนิดเดียว การเปลี่ยนต้องปลดก่อน
ข้อจำกัดจากพันธะหทัย การถือหุ่น สถานะเป้าหมาย และคูลดาวน์เดิมยังใช้ตามเดิม
ไม่ได้เปิดการเชื่อมหลายหุ่นทับคนเดียวหรือบังคับรักษาพันธะหลังตาย/ย้ายมิติ

เปอร์เซ็นต์ใช้ตัวคูณแยกจากระบบบัฟ/เกราะเดิม ผลต่างระบบจึงประกอบกันตาม pipeline เดิม
ไม่แก้ค่าเกราะหรือค่าพื้นฐานถาวร ดาเมจแบ่งปัน `thida:shared` ไม่คำนวณโบนัสอัลติซ้ำ

## ส่งต่อระบบพลังเวทย์

โค้ด: `ThidaMayaromScaling` แยกจาก `ThidaSkillIntegration` ของคาถาเดิม

```java
ThidaMayaromScaling.install(player -> myStats.magicPower(player));
// ถอดตัวเชื่อม:
ThidaMayaromScaling.install(null);
```

provider ต้องอ่านค่าอย่างเดียว ห้ามหักมานา เปลี่ยนบัฟ หรือทำดาเมจเอง
ค่าต้องเป็นตัวเลข finite >= 0 หากไม่ถูกต้องหรือ provider โยน exception จะใช้ดาเมจเดิม
สูตรทำงานใน LivingIncomingDamageEvent ก่อนการคำนวณเกราะของ Minecraft
ไม่มี dependency กับ Iron's Spellbooks และไม่คูณดาเมจเดิมสองเท่าเมื่อไม่มี provider
ขณะนี้บัฟ/ดีบัฟยังใช้ค่าพื้นฐานที่ตกลงไว้ ไม่ผูกกับม็อดสเตตัสที่ยังไม่ส่งมา

## ส่งต่อคนทำ AAA effects

ใช้ dispatcher และ resource mapping เดิม ไม่ต้องเรียกเอฟเฟกต์จากโค้ดดาเมจโดยตรง

| event | power | component | จุดยึด |
| --- | --- | --- | --- |
| `ULTIMATE_STARTED` | `mayarom` | `ultimate` | `USER` |
| `ULTIMATE_ENDED` | `mayarom` | `ultimate` | จุดเดิมของ instance |
| `ULTIMATE_HIT` | `mayarom` | `pulse` | ปรับ mapping เป็น `TARGET` ได้ |

อัลติมี projection แบบ START/SYNC/STOP ตามระบบ schema 2 เดิม
คนที่เข้าเกมทีหลังหรือรีโหลด resource ได้ snapshot ของเวลาที่เหลือ
เมื่อเจ้าของออฟไลน์หรือตาย ภาพหยุดชั่วคราวและกลับมาได้ โดยไม่ลบสถานะ gameplay
การย้ายมิติใช้ตำแหน่ง USER ปัจจุบันตาม snapshot
`ULTIMATE_HIT` เป็น one-shot พร้อม reason `MELEE_CURSE` หรือ `NILAKAN_ALL_SPELLS`
ตัวทำภาพอ่าน reason จาก event ได้ แต่ไฟล์ mapping เดิมยังไม่ได้เพิ่มตัวกรอง reason
ต้องใช้ instance/phase จัดการ loop ห้ามสร้าง loop ค้างจาก one-shot
ดูรายละเอียด adapter ใน [Guide เอฟเฟกต์](EFFECTS_INTEGRATION_GUIDE_TH.md) และตัวอย่างใน `docs/examples/`
ยังไม่ได้ใส่ไฟล์เอฟเฟกต์ AAA จริง ไอคอนดีบัฟใช้ภาพเดิมเป็น placeholder
มี mapping ปิดไว้ใน `assets/thida/thida_effects/mayarom.json` สำหรับภาพรอบตัวและภาพเมื่อโจมตี
คนทำเอฟเฟกต์เปลี่ยน resource เป็นของจริง ติดตั้ง backend และเปิด enabled ได้ตามระบบเดิม
