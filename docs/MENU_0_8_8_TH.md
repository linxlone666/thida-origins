# Thida 0.8.8 — เมนูคาถากะทัดรัด

ปรับเฉพาะการจัดวางเมนู WheelScreen จากความกว้างตายตัว 380 หน่วย GUI เป็นความกว้างตามหัวข้อ ชื่อรายการ และข้อความสถานะที่วัดด้วยฟอนต์ Itim ของ Thida รวมพื้นที่ไอคอนและ padding

กำหนดขั้นต่ำ 180 และเพดาน 272 หน่วย GUI พร้อมกันขอบจอ 8 หน่วยต่อข้าง ปัดความกว้างครั้งละ 8 หน่วยเพื่อลดการขยับเล็กน้อย คำแนะนำด้านล่างขึ้นบรรทัดใหม่ตามความกว้างจริง และความสูงกรอบรวมจำนวนบรรทัดคำแนะนำ

ยังอยู่กลางหน้าจอ ใช้ลูกกลิ้งเลือก คลิกซ้ายตรงไหนก็ได้เพื่อยืนยัน คลิกขวาหรือ Esc ย้อนกลับเหมือนเดิม ไม่เปลี่ยนคำสั่งร่ายสกิล คูลดาวน์ ผลสกิล หรือข้อมูลเซฟ

ตรวจโดยสร้าง JAR ผ่าน Gradle task `jar` ไม่เพิ่มหรือรัน tests ในรอบนี้
