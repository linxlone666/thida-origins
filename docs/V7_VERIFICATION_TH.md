# ผลตรวจรุ่นพัฒนา 0.7

ตรวจวันที่ 18 ตุลาคม 2569 (เวลาไทย) เป้าหมาย Minecraft 1.21.1 / NeoForge 21.1.233 / Java 21

## ผ่านแล้ว

- Unit tests 21 กรณี: รวมกติกาเฉลี่ย HP แล้วจำกัด Max HP แยกแต่ละคน ตัวเลขส่วนเกินไม่โอน
- GameTest ในเกมจริง 55 กรณี ทั้งแบบมีและไม่มี Iron’s Spellbooks พร้อม AdvancedFakePlayers/Carry On
- adapter มานาส่วนตัวจำลองได้รับ Max Mana แยกผู้รับและมีลำดับเหนือ Iron’s; ค่า Max Mana ไม่ถูกต้องไม่เติมอีกระบบแทน
- เลือดไหลนิลกาลครบ 5 ครั้งที่วินาที 1–5 เลือดไหลหทัยครบ 10 ครั้งที่วินาที 1–10 และล้างแล้วไม่เกิดครั้งสุดท้ายย้อนหลัง
- จุดเรียกเอฟเฟกต์เริ่มพยายามเชื่อม เริ่ม/หมดอมตะ และหมดอมตะหลังพันธะจบ โดยไม่ต้องติดตั้ง AAA adapter
- ทดสอบฟื้นมานาจริงจาก Max Mana: ธิดา Max Mana 250 ได้ 12.5 ผู้รับ Max Mana 400 ได้ 20 และจำกัดไม่เกิน Max Mana
- กาฝาก: สิทธิ์ปลด ตำแหน่งช่องเก็บของ กระเป๋าเต็ม การยืนยันหลัง HP ลดจริง ปฏิเสธไม่คืนดาเมจ การเฉลี่ย/แบ่งดาเมจ overkill ตายได้ทั้งคู่ คูลดาวน์พัก Passive และ token ใช้แล้วใช้ซ้ำไม่ได้
- หทัย: เกณฑ์ HP มากกว่า 50 ประวัติเป้าหมาย ช่วยตายหนึ่งครั้งและช่วงอมตะ 5 วินาที บล็อกเฉพาะฮีลตนเองจากสกิล ฮีลอื่นก่อนจบพันธะ การกันดีบัฟ และคูลดาวน์ยกเลิกก่อน/หลังเส้นตาย
- Skill 1: adapter ที่ขาดข้อมูลไม่หักมานาหรือเริ่มคูลดาวน์ ใช้ test adapter ตรวจการแทนผลเดิม การปลดแล้วลบผล ระยะไกล ข้ามมิติ เลือดไหลทุกวินาทีแบบไม่ฆ่า และต้องถือหุ่นชิ้นที่เชื่อมจริง
- บันทึก SavedData และโหลดคืน: UUID เป้าหมาย สิทธิ์ปลด และประวัติยังอยู่
- เปิดโลกสำเนา `thida-crash-copy` ด้วยม็อดใน DRC จริง และกู้บอทที่บันทึกไว้ได้ มี `THIDA_WORLD_JOIN_SMOKE_PASS` และ `THIDA_AFP_RESTORE_COMPLETE`
- เห็น HUD รายชื่อ ไอคอน และหน้าสกินใน client จริง
- build สำเร็จ JAR รุ่นทดสอบไม่รวมคลาส GameTest หรือ UI smoke

ชุด GameTest เก่าที่กำหนดกติกา 0.6 ต่างจากข้อยืนยันล่าสุด เก็บต้นฉบับที่ `migration-legacy/ThidaGameTests-v6.java.txt`
กรณีที่เปลี่ยนถูกแทนด้วยการทดสอบกติกาใหม่ ไม่ได้รายงานชุดเก่าว่าผ่านโดยไม่รัน

## คำสั่งสำคัญ

ตั้ง JAVA_HOME ไป `.tooling/java/jdk-21.0.12.1+1` และ GRADLE_USER_HOME ไป `.gradle-cache`

```text
gradlew.bat test runGameTestServer build -PfakePlayerProfile="C:/Users/linxs/AppData/Roaming/ModrinthApp/profiles/DRC 1.0.0" --console=plain
gradlew.bat verifyWorldJoinSmoke -PwithoutIron=true -PcompatProfile="C:/Users/linxs/AppData/Roaming/ModrinthApp/profiles/DRC 1.0.0" -PwithConnector -PallProfileMods --console=plain
```

Log รุ่นส่งมอบ: `v7-personal-integration-no-iron.log`, `v7-personal-integration-with-iron.log`; ผล unit tests อยู่ `build-neoforge/test-results/test/`
Log เปิดโลกสำเนารอบก่อนเก็บ integration และ HUD เพิ่มเติม: `v7-world-join.log`
รุ่นเสถียร 0.6.5 และโลกในโปรไฟล์เล่นจริงไม่ได้ถูกแทนระหว่างตรวจ

## ขอบเขตของผลตรวจ

ทดสอบด้วย FakePlayer ที่เปิดรับดาเมจจริง และบอท AdvancedFakePlayers ไม่ใช่การทดสอบเครือข่ายผู้เล่นจริงหลายเครื่อง
การระบุแหล่งฮีลของม็อดอื่นต้องใช้ `ThidaHealing` adapter ถ้าระบุไม่ได้ใช้ fallback ที่ตกลงไว้
สกินใช้ข้อมูลที่ client เห็น รองรับ texture สกิน ไม่รับประกัน renderer 3D ของ Figura ทุกตัว
HUD ผู้รับกำหนดตำแหน่งกึ่งกลางเหนือบริเวณเลเวล/หัวใจ และเพิ่มการลากแนวตั้งให้เว้นพื้นที่ Fragment ได้ การลากและเมนูรุ่นส่งมอบยังไม่ได้ตรวจด้วยมือครบทุกความละเอียด เนื่องจากเจ้าของงานหยุด Computer Use ระหว่างรอบก่อน
Skill 1 ยังไม่เปิดใช้จริงจนได้ม็อดมานา สูตรสเกล/เพดาน และฐาน/จำนวนฮีล
โบนัสลดดาเมจ 10 วินาทีหลังกาฝากแตกยังไม่ใส่ตัวเลข เพราะยังรอสูตร
ULT ยังไม่ตัดสินใจ ไม่มีการเพิ่มเอฟเฟกต์ AAA หรือ dependency ใหม่

## เกณฑ์จบงานรอบนี้

ส่วนที่ระบุว่ารอสูตร/API จึงส่งมอบเป็น adapter พร้อมเอกสารและการปฏิเสธร่ายที่ไม่เดาตัวเลขตามข้อกำหนด ไม่เปลี่ยนเป็นการใช้ Iron’s แทน
