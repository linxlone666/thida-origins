# Thida 0.8.9 — คำแนะนำเมนูบรรทัดเดียว

ย่อคำแนะนำด้านล่างเป็น “ลูกกลิ้ง: เลือก / คลิกขวา/Esc: กลับ” และวาดด้วย fittedText บรรทัดเดียว ถ้าพื้นที่ไม่พอจะลดขนาดเฉพาะคำแนะนำให้พอดี ไม่ตัดคำหรือขยายความกว้างเมนู ความสูงกรอบคืนพื้นที่บรรทัดที่สอง

คงเมนูแบบกะทัดรัดและวิธีควบคุมเดิม ไม่เปลี่ยนกติกาสกิลหรือเซฟ สร้าง JAR ด้วย Gradle ไม่ได้รัน tests หรือตรวจภาพ client ใหม่ในรอบนี้
