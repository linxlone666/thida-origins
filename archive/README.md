# Original release archive

One directory per recovered milestone. JARs are original local release artifacts, not fresh builds. Read PROVENANCE.json before assuming a source snapshot is available. SHA256SUMS.txt verifies the archived JAR, and SOURCE_SHA256SUMS.txt verifies the saved source snapshot when available.

Do not use old Forge releases with the current NeoForge profile. Current supported source is at the repository root. See ../HISTORY.md for the complete reconstructed timeline and missing-source limitations.

This archive excludes dependency JARs, user worlds, credentials, logs, caches, and the restricted ThaiFontFix font pack. Licensed Itim assets and their OFL notices remain inside the corresponding Thida releases.
