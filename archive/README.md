# Original release archive

One directory per recovered milestone. JARs are original local release artifacts, not fresh builds. Read PROVENANCE.json before assuming a source snapshot is available. SHA256SUMS.txt verifies the archived JAR, and SOURCE_SHA256SUMS.txt verifies the saved source snapshot when available.

Do not use old Forge releases with the current NeoForge profile. Current supported source is at the repository root.

These milestones were imported from saved files; commit timestamps are import times, not original development timestamps. Tags beginning `archive/` may contain only the release binary and notes: source at those tags can be an earlier recovered snapshot. The presence of source does not establish a reproducible match to an archived JAR. Read each milestone's PROVENANCE.json for its specific source availability.

This archive excludes dependency JARs, user worlds, credentials, logs, caches, and the restricted ThaiFontFix font pack. Licensed Itim assets and their OFL notices remain inside the corresponding Thida releases.
