# ผลตรวจฟอนต์ Thida 0.8.4

- build ผ่าน และ unit tests 35 รายการผ่าน
- client visual test ผ่านทั้งเมื่อไม่มีแพ็กเสริมและเมื่อเปิด `ThidaThaiFont-local.zip`
- วัดข้อความไทยเดียวกันได้ default=49 และ thida=57 หน่วย GUI แสดงว่า font namespace ใหม่ใช้ metrics แยกจากฟอนต์ปกติของเกม
- ตรวจภาพ HUD และปุ่ม editor จริงแล้ว ฟอนต์ไทยเปลี่ยนเป็นแบบที่ให้มา ชื่อยาวตัดตามความกว้างฟอนต์ใหม่ และ grid สองคอลัมน์ยังทำงาน
- source ZIP/JAR ไม่มีไฟล์ TTF ไฟล์ฟอนต์อยู่ในแพ็กเสริมเฉพาะเครื่องที่สร้างจาก ThaiFontFix ของผู้ใช้ พร้อม metadata ที่มา
- ยังไม่ได้ตรวจ tooltip ด้วยภาพแยกหรือทดสอบ DRC ทั้งแพ็ก การใส่ฟอนต์ tooltip ตรวจจากการกรอง namespace Thida และการตั้ง Component style ฝั่ง client
- ไม่เปลี่ยนกติกาสกิลหรือข้อมูลเซฟ และไม่ได้แก้ options/ติดตั้งแพ็กในโปรไฟล์ DRC จริงโดยอัตโนมัติ

ใช้ JAR 0.8.4 แทน Thida เดิม แล้ววาง `ThidaThaiFont-local.zip` ใน resourcepacks และเลือกเปิดในเกม หากต้องการเปลี่ยนเฉพาะ Thida ให้ปิด ThaiFontFix ฉบับที่เปลี่ยนฟอนต์ทั้งเกม ใช้แพ็กเสริมนี้แทน รายละเอียดอยู่ใน `FONT_0_8_4_TH.md`
