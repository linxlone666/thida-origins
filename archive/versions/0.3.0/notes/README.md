# ธิดา — Origins สำหรับ Minecraft Forge 1.20.1

รุ่น **0.3.0** เพิ่ม HUD สายสัมพันธ์ คูลดาวน์ และเสียงแจ้งเตือน บนระบบหุ่นและพันธะตามสเปกที่ยืนยันวันที่ 14 กันยายน 2026

## ติดตั้ง

1. Minecraft Java **1.20.1**, Java **17**, Forge **47.4.0**
2. Origins Forge **1.20.1-1.10.0.9** และ Caelus **3.2.0+1.20.1** ตาม dependencies เดิมของโปรเจกต์
3. ใส่ `thida-origins-1.20.1-0.3.0.jar` ใน `mods` ทั้งเครื่องผู้เล่นและเซิร์ฟเวอร์ แทน JAR ธิดารุ่นเดิม
4. เลือก Origin **ธิดา** จะได้รับนิลกาลและนรตราอัตโนมัติ ใช้ `/thida kit` รับไอเทมสกิลทั้งหมด

Origin และทรัพยากรรวมอยู่ใน JAR ไม่ต้องติดตั้ง ZIP ซ้ำ สำหรับโลกเดิมใช้ Orb of Origin หรือ `/origin set <ชื่อผู้เล่น> origins:origin thida:thida`

## การควบคุม

- **นิลกาล:** ถือหุ่นตีผู้เล่นเพื่อเชื่อมเป้าหมายดีบัพ
- **นรตรา:** ถือหุ่นมองหน้าผู้เล่นต่อเนื่อง 10 วินาทีเพื่อเชื่อมเป้าหมายบัพ อีกฝ่ายไม่ต้องมองกลับ
- **สกิล 1:** ถือหุ่น Passive แล้วกด **เลข 1** เปิดเมนู จากนั้น **2 / 3 / 4** ส่งผล หรือ **5** ยกเลิกการเชื่อม; Esc ปิดเมนู
- เมนูเลขใช้ขณะเล่น ไม่มีหน้าจออื่นเปิดอยู่ เลือกหุ่นมือหลักก่อนมือรอง และไม่เปลี่ยนช่อง hotbar เมื่อเปิดเมนู
- ทางเลือก: Shift+คลิกขวาหุ่นเพื่อวนเลือกผล และคลิกขวาเพื่อส่งผล
- **สกิล 2:** คลิกขวาไอเทมหุ่นกาฝากเพื่อเสกหุ่น แล้วตีผู้เล่นเพื่อเชื่อม คลิกขวาอีกครั้งเพื่อยกเลิก
- **สกิล 3:** ถือหุ่นพันธะ เล็งผู้เล่นแล้วคลิกขวา คลิกขวาอีกครั้งเพื่อยกเลิก
- **โดเมน:** คลิกขวาเครื่องราง ศูนย์กลางคือพิกัดผู้ใช้ตอนกางและไม่เคลื่อนตามตัว

## HUD และเสียงแจ้งเตือน

HUD มุมซ้ายบนแสดงชื่อเป้าหมายของนิลกาล นรตรา กาฝาก และพันธะหทัย พร้อมสถานะไม่พร้อมรับผลเมื่อเป้าหมายออฟไลน์/ตาย คูลดาวน์แสดงเป็น `นาที:วินาที` โดยแยกปุ่ม 2–4 ของหุ่น Passive ในเมนูเลขก็เห็นคูลดาวน์ด้วย

- ความคืบหน้ามองนรตราและชื่อคนที่กำลังมอง
- กาฝากรอเชื่อม / หุ่นถูกล็อกด้วยเงื่อนไขสกิล
- สิทธิ์อมตะของพันธะหทัยเหลือหรือใช้แล้ว; ผู้ถูกดูแลเห็นชื่อผู้ดูแลและเวลาอมตะ แม้ไม่ได้เป็นธิดา
- เวลาโดเมนที่เหลือ, อยู่ในหรือนอกเขต, คูลดาวน์หลังจบโดเมน
- เสียงเฉพาะผู้เล่นเมื่อเชื่อมสำเร็จ, การเชื่อมสิ้นสุด, เสกกาฝาก, กาง/จบโดเมน, อมตะเริ่ม และคูลดาวน์พร้อมใช้ ไม่มีเสียงทุกวินาที

ข้อมูลส่งจากเซิร์ฟเวอร์ให้ผู้เล่นเจ้าของข้อมูลทุก 5 ticks (ประมาณ 0.25 วินาที) และนับเวลาต่อบน client ระหว่าง packet ไม่เล่นเสียงย้อนหลังเมื่อล็อกอิน ข้อมูลถูกล้างเมื่อออกจากเซิร์ฟเวอร์

ตั้งค่าใน `config/thida-client.toml` ของแต่ละเครื่อง: `showHud` เปิด/ปิด HUD, `cueSounds` เปิด/ปิดเสียง, `cueVolume` ความดัง 0–1, `hudX` / `hudY` ตำแหน่งมุมซ้ายบน HUD ซ่อนเมื่อ F1 ซ่อน GUI หรือเปิด F3; ชื่อยาวตัดท้ายเพื่อไม่ล้นจอ

ต้องอัปเดต JAR เป็น **0.3.0 ทั้ง client และ server** เพราะมี packet HUD ใหม่
## Config และโลกเดิม

Config อยู่ที่ `<โลก>/serverconfig/thida-server.toml` รุ่นนี้ใช้คีย์ใหม่ `domainActiveSeconds=300`, `dollEffectSeconds=20`, `parasiteCasterBreakHealth=25` เพื่อไม่รับค่าฉบับเก่า 15/10/50 โดยไม่ตั้งใจ คีย์เก่า `domainDuration`, `effectSeconds`, `parasiteBreakHealth`, `parasiteThreshold`, `markRange` ไม่ใช้แล้ว

คูลดาวน์ส่งผลแยกประเภท 30 วินาที; คูลดาวน์หลังยกเลิกหุ่น/พันธะ 600 วินาที; โดเมนคูลดาวน์ 1200 วินาทีหลังหมดเวลา 300 วินาที

ค่าที่คงเป็นสมมติฐานปรับได้: แบ่งดาเมจ 50/50, ฮีลนรตรา 8 HP, ดีบัพรับดาเมจเพิ่ม 30% ส่วนฮีลหลังหุ่นกาฝากแตกเพิ่ม 50 HP ตามสเปก โดยจำกัดที่ max health ปัจจุบัน **2 HP = 1 หัวใจ** ม็อดไม่เพิ่ม max health ให้เอง

หุ่นกาฝากที่เสกใช้ Armor Stand ขนาดเล็กหัวฟักทองเป็นรูปลักษณ์ชั่วคราว นรตราในโดเมนยังหมายถึงผู้เล่นที่เชื่อมกับหุ่น เช่นเดียวกับระบบเดิม ไม่มี AI หุ่นต่อสู้แยกตัว
