# หุ่นผูกกับช่องเก็บของผู้เล่น — 0.7.1

นรตรา นิลกาล กาฝาก และ heart_doll เก่าสำหรับความเข้ากันได้ ย้ายระหว่างช่องของผู้เล่นและมือรองได้ แต่โยนหรือใส่ช่องเก็บของภายนอกไม่ได้

- กัน Q/Ctrl+Q และปุ่มโยนในกระเป๋า
- กันคลิกวางในกล่อง ช่องคราฟต์ เตาหลอม และช่องภายนอก รวม Shift-click, ปุ่ม hotbar สลับของ และลากกระจายข้ามไปช่องภายนอก
- ไม่รับเข้า bundle/ไอเทมเก็บของที่เคารพ canFitInsideContainerItems
- ฝั่ง client ไม่ลบหุ่นทำนายตอนกด Q ฝั่ง server ตรวจซ้ำและคืนสถานะช่องเก็บของเมื่อปฏิเสธ
- หุ่นบนเคอร์เซอร์ขณะย้ายช่องยังถือว่าอยู่กับตัว ไม่ทำให้กาฝากแตกหรือ Passive พักผล
- หุ่นที่ควรคงอยู่หลังตายไม่ตกพื้น เก็บข้อมูลไว้คืนหลังเกิดใหม่ ถ้ากระเป๋าเต็มจะรอคืนเมื่อมีที่ว่าง
- กาฝากที่แตกเพราะตายหรือเหตุเดิมยังถูกใช้หมดตามกติกา ไม่สร้างหุ่นใหม่จากสำเนาที่เก็บไว้
- การปลดสายสัมพันธ์ในเมนูยังใช้ได้ ไม่มีการเพิ่มการยกเลิกกาฝากด้วยตนเอง

โค้ดหลัก: ThidaDollInventory, DollContainerMixin, DollSlotMixin, DollClientDropMixin และ AbilityItem
ThidaPassives/ThidaBonds นับหุ่นที่ถือบนเคอร์เซอร์หรือที่รอคืนหลังเกิดใหม่ด้วย
ข้อความไทยทั้งสอง locale ปรับให้ตรงกับข้อห้ามใหม่

รอบนี้สร้าง JAR ด้วย `gradlew.bat jar -PwithoutIron=true` ไม่ได้เพิ่มหรือรัน tests และยังไม่ได้ตรวจพฤติกรรมในเกมจริงของรุ่น 0.7.1
การย้ายผ่าน API เฉพาะของม็อดอื่นที่เขียน inventory โดยตรงและไม่ผ่านช่องเก็บของมาตรฐาน ต้องตรวจเข้ากันได้กับม็อดนั้นเป็นรายกรณี
คำสั่งผู้ดูแลอย่าง /clear และการลบไอเทมด้วยระบบกาฝากแตกไม่ได้ถูกห้าม
