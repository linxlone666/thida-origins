# Thida Origins 0.8.1 — เล่นด้วยค่าพื้นฐานและจัด HUD แยก

เริ่มจาก source ส่งมอบ 0.8.0 ใน workspace โดยเก็บชุดเดิมไว้

## จากงาน cleanup รุ่น 0.8.0

- เอาเส้นทางร่ายเก่าที่เข้าไม่ถึง config ที่เลิกใช้ import/field ที่ไม่มีผู้ใช้ และ packet ล้มเหลวซ้ำออก
- จัดรูปแบบ Java รวมเลขรุ่นใน gradle.properties และย้ายข้อความไทยไป translation keys
- รวม dispatcher ภาพเป็น schema 2 แยกข้อมูลคาถา/สาเหตุ มี instance และ lifecycle สำหรับหยุด/กลับมาแสดงภาพ
- API provider อ่าน quote โดยไม่จ่าย หักค่าร่ายเพียงครั้งเดียว และปฏิเสธการจ่ายที่ล้มเหลวก่อนเปลี่ยนคาถา/CD
- ชุดส่งมอบใช้ allowlist จึงไม่ติด cache/log/โลก/release เก่า แต่ไม่ได้ลบโลกหรือประวัติจากเครื่อง
- ยังรักษา registry/NBT และ mixin ที่จำเป็นต่อโลกเก่า

## เปลี่ยนใน 0.8.1

- ถอด ThidaIronMana, dependency/repository สำหรับ Iron’s และ dependency ที่นำมาใช้กับระบบนั้นเท่านั้น
- ถอด optional dependency จาก metadata และตัวเลือก WithoutIron จากสคริปต์ build
- มานา Passive ใช้เฉพาะ ThidaManaIntegration.Adapter หากไม่มี provider จะข้ามการเติมมานา
- ปรับ regression เดิมให้ตรวจการเชื่อมและชำระดีบัฟโดยไม่มี provider แทนการเรียก API Iron’s
- หากไม่มี skill provider ใช้ค่าพื้นฐานที่เจ้าของงานยืนยัน: เปอร์เซ็นต์ 20%, เลือดไหล 2 HP/วินาที, ฮีล 20% ของ Max HP เป้าหมาย, ป้องกันหลังกาฝากแตก 20%, ร่ายฟรี
- ยังติดตั้ง skill provider เพื่อกำหนดสเกลและราคาได้ หากติดตั้งแล้วไม่พร้อม/ข้อมูลผิดจะไม่เปลี่ยนไปร่ายฟรี
- ปุ่ม H เปิดหน้าจัด HUD โดยเฉพาะ เปลี่ยนได้ใน Controls และเอารายการจัด HUD ออกจากเมนูคาถา
- ลากได้ทั้งสามแผง ปรับขนาดรายแผง 60–140% ด้วยลูกกลิ้งหรือ −/+ คืนค่าแผงที่เลือกและบันทึกได้
- HUD สายสัมพันธ์แคบลง มีหัวสกิน ชื่อ ชนิดหุ่น HP และแถบเลือด; แถบผู้รับและไอคอนใช้กรอบโปร่งแสงแบบเดียวกัน
- ถือหุ่นชนิดเดียวเปิดคาถาทันที ถือสองชนิดต่างกันจึงขึ้นเลือกหุ่น
- แก้การเรียก blur ซ้ำที่ทำให้ข้อความเมนูและ HUD ถูกเบลอหลังวาด

## การตรวจ

- build, unit tests 30 รายการ และ GameTests 62 รายการผ่านใน runtime ขั้นต่ำโดยไม่มี Iron’s หรือ AAA
- GameTests ตรวจคาถาพื้นฐาน การลดดาเมจ ฮีลตาม Max HP เป้าหมาย ล้างดีบัฟ และเลือดไหลโดยไม่มี provider รวม regression เดิม
- ไคลเอนต์ในสำเนาโลกทดสอบตรวจเมนูหนึ่ง/สองหุ่น การลาก ย่อขยาย และคงค่าหลังเปิด editor ใหม่ พร้อมจับภาพหน้าจอ
- runHudPreview เป็น dev-only ใช้โลกทิ้งได้ชื่อ hud-preview ใน run-neoforge-hud-preview/saves ต้องเตรียมโลกแยกก่อนเรียก ไม่บรรจุโลกในชุดส่งมอบ

ยังไม่มี AAA backend/ไฟล์เอฟเฟกต์จริง แต่ event/mapping/lifecycle และเอกสารส่งต่อยังอยู่ ไม่ได้ทดสอบกับม็อดแพ็ก DRC ทั้งชุดหรือหลายเครื่องในรอบนี้
