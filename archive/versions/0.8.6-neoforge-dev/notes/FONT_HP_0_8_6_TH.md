# Thida 0.8.6 — ตรวจสัดส่วนฟอนต์และแก้ HP ถูกตัด

## สิ่งที่ตรวจพบ

เมื่อเปลี่ยนตระกูลฟอนต์ ขนาดที่เห็นและความกว้างข้อความเปลี่ยนได้แม้ใช้ HUD scale เดิม จาก log ทดสอบข้อความเดียวกัน “ความเร็ว ทดสอบ” ฟอนต์ ThaiFontFix ที่เคยใช้ในแพ็กเสริมวัดได้ 57 หน่วย GUI และ Itim ที่ตั้งขนาด 11 วัดได้ 71 หน่วย GUI (กว้างขึ้นประมาณ 25%) ตัวเลขนี้เป็นการเทียบความกว้างข้อความ ไม่ใช่ความสูงตัวอักษรหรือเปอร์เซ็นต์ของ HUD scale

รุ่นนี้คง Itim provider size **11** และค่าตั้ง HUD scale เดิม ไม่เปลี่ยนไฟล์ฟอนต์หรือกติกาสกิล การ fit แผงเข้าหน้าจอของระบบ HUD ยังทำงานตามเดิม

## แก้ HP

- เดิมใช้ความกว้างเลข `8` ซ้ำเพื่อจองช่อง HP ซึ่งไม่รับประกันว่ากว้างพอกับทุกหลักในฟอนต์แบบ proportional หรือแพ็กที่ override ฟอนต์
- เปลี่ยนเป็นวัดเลข 0–9 จากฟอนต์ที่วาดจริง เลือกความกว้างสูงสุด แล้วจองตามจำนวนหลักของ Max HP พร้อมช่อง ` / ` จึงไม่ทำให้ช่องกว้างสั่นตาม HP ปัจจุบัน
- ข้อความค่า HP ใช้ `fittedText` แทนการตัดด้วย ellipsis หากเจอค่าที่ยาวเกินพื้นที่สูงสุดจะ fit เฉพาะข้อความนั้นให้ครบ ไม่กลายเป็น `100 / 1…` และไม่เขียนทับค่าจริง
- เพิ่ม client assertions สำหรับ Max HP 100, 999, 1000, 9999 และ 1000000 กับ HP หลายค่า และเปลี่ยนข้อมูลตัวอย่างให้มี `100 / 100` กับ `16 / 20` ตามภาพที่ผู้ใช้ส่ง

## ชื่อไอเทม

เปลี่ยนเฉพาะ `item.thida.parasite_doll` ใน `th_th.json` และ `en_us.json` เป็น **ตุ๊กตากาฝาก** ไม่มีคำว่า “แบ่งปันความเสียหาย” ต่อท้ายชื่อ ผลและคำอธิบายระบบแบ่งปันความเสียหายยังคงเดิม

## การทำงานร่วมกับ ThaiFontFix

โปรไฟล์ DRC ที่ตรวจใช้ GUI Scale 3 และเปิด ThaiFontFix-1.0.8 อยู่ จึงตรวจเพิ่มใน client แยกโดยใช้แพ็กเดียวกัน พบ native crash ระหว่าง FreeType โหลด glyph หนึ่งครั้ง การอ้าง `minecraft:default` เป็น fallback ทำให้ฟอนต์ของแพ็กถูกแชร์ข้าม font sets ที่เกมเตรียมพร้อมกัน จึงเปลี่ยน fallback ของ Thida เป็น `minecraft:include/unifont` ซึ่งใช้ Unihex แทน TTF ของแพ็ก Primary font ยังเป็น Itim size 11 เดิม

ข้อสรุปเรื่องการโหลดพร้อมกันอ้างอิง stack trace และโค้ด FontManager/TrueTypeGlyphProvider ของ Minecraft 1.21.1 ที่ตรวจในเครื่อง ไม่ได้แก้ font ของเกม ไม่แก้แพ็กของผู้ใช้ และไม่เพิ่ม mixin หรือ dependency

## การตรวจและขอบเขต

รัน `formatJava build runHudPreview -PwithoutIron=true` ตรวจ geometry และภาพจริง พร้อม unit test ภาษาไทยที่ยืนยันชื่อไอเทมใหม่ ชุด visual test เป็นข้อมูลตัวอย่าง client ไม่แก้สายสัมพันธ์หรือร่ายสกิลจริง ผลตรวจและภาพในชุดส่งมอบ ไม่ได้ติดตั้งลง DRC หรือแก้ options จริงโดยอัตโนมัติ

ฟอนต์ Itim และ SIL OFL 1.1 ใน JAR ยังเหมือนรุ่น 0.8.5 ดูใบอนุญาตและที่มาได้ใน `META-INF/licenses/Itim/`
