## สิ่งที่เปลี่ยน

1. วัดความกว้างจาก font ของเกม + ไอคอน/สกิน/ช่องว่าง แผงชื่อสั้นลดจาก 208 เหลือขั้นต่ำ 158 หน่วย GUI (ประมาณ 24%) ชื่อยาวมีเพดาน 224 และตัดเฉพาะภาพด้วย …
2. หลอด HP จำกัดที่ 108 หน่วย จากเดิม 147 (สั้นลงประมาณ 27%) ไม่เปลี่ยนความยาวตาม HP ปัจจุบัน กันพื้นที่ตัวเลขตาม Max HP
3. สถานะออฟไลน์/พักผลแสดงข้อความชัดเจน พร้อมบอกว่าไม่ทราบ HP ปัจจุบัน ไม่ใช้ค่าที่ cache เป็นเลือดปัจจุบัน
4. แผงผู้รับและผลสกิลมีเฉพาะสถานะที่มีอยู่จริง จัดแถวใหม่ได้ มีช่องเวลาคงที่ แผงยุบเมื่อสถานะหาย และยังแสดงช่วยชีวิตขณะพันธะทำงานแม้ไม่มีบัฟตามเวลา
5. ใช้พิกัด GUI หลัง scale กันพื้นที่ vanilla และเป้าเล็ง หน้าจอเล็กอาจลด scale ที่แสดงจริงเพื่อให้พอดีโดยไม่เปลี่ยนค่าที่ตั้ง; editor แจ้งค่า “พอดีจอ”
6. พื้นที่ลากกับกรอบเลือกใช้ขนาดจริง กลุ่มผลสกิลรับเมาส์เฉพาะการ์ดที่วาด ไม่รับช่องว่างท้ายแถว ตัวอย่างอยู่เฉพาะ editor

ไม่ได้เปลี่ยนคลาสสกิล ดาเมจ คูลดาวน์ หรือข้อมูลเซฟเกม เทียบ hash กับ backup แล้วการเปลี่ยนไฟล์เดิมจำกัดอยู่ใน HUD/ภาษา/รุ่น/เครื่องมือจัดชุดและ visual test เพิ่ม `HudPacking`, `HudPackingTest` และคู่มือภาษาไทยใหม่ ข้อความไทยเดิมทั้งหมดมีค่าเดิม ไม่เปลี่ยนคำตอบหรือรายละเอียดสกิล

### อักษรส่วนเกิน

ไม่พบ marker literal เดี่ยว “ท” หรือ “จ” ในโค้ด HUD หรือ locale ของฐาน 0.8.1 จึงยังยืนยันต้นทางของอักษรสองตัวนั้นโดยเฉพาะไม่ได้ พบจุดเสี่ยงที่พิสูจน์จากโค้ดได้คือคำว่า “รอ” ในช่องเพียง 12 หน่วย และ `badge.key` ในช่อง 8 หน่วย เลิกวาดป้ายจิ๋วเหล่านั้นแล้ว ใช้ชื่อผลกับคำว่า “พัก” ที่วัดความกว้างครบ และข้ามข้อความ null/ว่าง/พื้นที่แคบเกินอ่านแทนการวาดเศษอักษร ไม่พบ marker หรือ translation key ดิบในภาพที่ตรวจ

## ข้อจำกัดและส่วนที่ยังไม่ได้ตรวจ

- ตรวจใน client/dev runtime ของ NeoForge 21.1.233 กับ Origins/Jupiter โดยไม่ติดตั้ง Iron’s หรือ AAA ไม่ได้รันม็อดแพ็ก DRC เต็มชุดหรือเซิร์ฟเวอร์หลายเครื่องในรอบนี้
- ไม่ได้ทดสอบ resource pack ที่เปลี่ยน font หรือ HUD จากม็อดอื่น ซึ่งอาจมีพื้นที่สงวนต่างจาก vanilla
- ตัวอย่างสถานะเป็นข้อมูลจำลองฝั่ง client ไม่ใช่การรอให้ผู้เล่นจริงเชื่อม/ตาย/ออฟไลน์ทุกกรณีในการเล่นหลายคน กติกาไม่ได้ถูกแก้ และตรวจ regression แยกด้วย GameTests
- ตรวจโค้ดปุ่มคืนค่าเดิมแล้ว แต่ไม่ได้กดทดสอบคืนค่าด้วยมือครบทั้งสามแผง
- กรณีพื้นที่น้อยจริง การแสดงผลอาจถูก fit ต่ำกว่าเปอร์เซ็นต์ที่ผู้เล่นตั้งไว้ editor แจ้งค่าจริงแล้ว
- `recipientHudOffsetY` เปลี่ยนมาอ้างขอบล่างเพื่อรักษา anchor เมื่อจำนวนแถวเปลี่ยน ตำแหน่งเดิมอาจขยับขึ้นและปรับกลับได้ด้วย H; ไม่เปลี่ยนข้อมูลสายสัมพันธ์ฝั่งเซิร์ฟเวอร์

นำ JAR ใหม่ไปแทน JAR Thida เดิมโดยเก็บ Thida เพียงรุ่นเดียวในโฟลเดอร์ mods ชุดนี้ยังไม่ได้คัดลอกไปทับโปรไฟล์ Modrinth ของผู้ใช้
