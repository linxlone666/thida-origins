# ผลตรวจ HUD 0.8.3

- build ผ่าน และ unit tests 35 รายการผ่าน รวม test ใหม่ตรวจแนวคอลัมน์ของ grid
- client visual test รอบสุดท้ายผ่าน `THIDA_HUD_PREVIEW_PASS` ตรวจ GUI Scale 2/3, HUD 60/100/140%, ลาก/ปรับขนาด/เปิด editor ใหม่ และหน้าต่างหลายขนาด
- ตรวจภาพจริงยืนยัน HUD สกิลไม่มีชื่อหรือคำว่าพัก เหลือไอคอน เวลา และแถบความคืบหน้า
- สถานะผู้รับเรียงสองคอลัมน์ ไอคอนและช่องเวลาตรงกันระหว่างแถว
- คำแนะนำ editor ใช้ช่องว่างและ `/` แทนตัวคั่น `·` ที่ปรากฏเหมือนอักษร “ท” ในภาพของผู้ใช้
- รอบตรวจภาพแรกถูกเปลี่ยนไปหน้า Options และล้มเหลว จึงไม่นับรอบนั้น ใช้ผลรอบสุดท้ายหลังรันซ้ำเท่านั้น
- ภาพใน `screenshots/` มาจาก client จริงด้วยข้อมูลตัวอย่างฝั่ง client ไม่สร้างพันธะหรือร่ายสกิล ไม่มี visual test อยู่ใน JAR
- ไม่ได้ทดสอบ DRC ทั้งแพ็กหรือ font/resource pack ของผู้ใช้ในรอบนี้ และไม่ได้รัน GameTests ฝั่งเซิร์ฟเวอร์ซ้ำสำหรับ 0.8.3 เพราะเปลี่ยนเฉพาะการวาด HUD กับคำนวณ layout

ไฟล์ JAR ใหม่และ source ZIP อยู่ข้างเอกสารนี้ คู่มือภาษาไทยคือ `HUD_0_8_3_TH.md` ซอร์สหลักบนไดรฟ์ I: แก้แล้ว และสำรอง 0.8.2 ไว้ก่อนแก้ ไม่ได้ติดตั้ง JAR ทับโปรไฟล์ Modrinth อัตโนมัติ
