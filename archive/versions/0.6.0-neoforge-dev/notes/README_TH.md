# Thida Origins 0.6.0-neoforge-dev — ชุดทดสอบภาษาไทย

**รุ่นนี้ถูกแทนที่ด้วย 0.6.1** เนื่องจากพบปัญหาเปิด Singleplayer ใน DRC ใช้ชุด `../0.6.1-neoforge-dev/` แทน เก็บ JAR นี้ไว้เป็นสำเนารุ่นก่อนเท่านั้น

JAR สำหรับ Minecraft 1.21.1 NeoForge 21.1.233 และ Origins ของ IAFEnvoy 0.4-beta.2 ใช้ Java 21 ติดตั้งแอดออนเวอร์ชันเดียวกันทั้ง client/server

- [วิธีใช้ Passive ทั้งสอง](PASSIVES_TH.md)
- [เวอร์ชัน dependency การย้ายและผลตรวจสอบ](MIGRATION_1_21_1_TH.md)
- [จุดเชื่อมต่อเอฟเฟกต์สำหรับพัฒนาต่อ](PASSIVE_EFFECTS.md)

โปรไฟล์ DRC 1.0.0 ที่ตรวจยังไม่มี Iron’s Spells ’n Spellbooks, Iron’s Lib และ GeckoLib ต้องเพิ่มม็อดเหล่านี้เพื่อให้ฟื้นมานาได้ ส่วนการเชื่อม โบนัสนิลกาลและการล้างดีบัฟยังทำงานเมื่อไม่มี Iron’s

JAR มีข้อมูล Origin รวมอยู่แล้ว ไม่ต้องติดตั้ง datapack ซ้ำ รายละเอียดการเลือกเวอร์ชันและข้อจำกัดอยู่ในเอกสารการย้าย

ผ่าน unit tests และ GameTest 38 รายการทั้งกรณีมี Iron’s และไม่มี Iron’s พร้อมตรวจเริ่ม client แบบแยก โหลดโมเดลและ texture เดิมครบ ยังต้องทดลองด้วยผู้เล่นจริงใน DRC ทั้งชุด
