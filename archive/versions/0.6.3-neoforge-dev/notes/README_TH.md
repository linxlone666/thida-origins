# ธิดา 0.6.3 — ข้อความในเกมภาษาไทย

ใช้กับ Minecraft 1.21.1 NeoForge 21.1.233, Origins ของ IAFEnvoy 0.4-beta.2 และ Java 21 ติดตั้งรุ่นเดียวกันทั้ง client/server และใช้ JAR ธิดาเพียงรุ่นเดียวใน mods

แปลข้อความผู้เล่นของธิดาเป็นภาษาไทย ใช้ภาษาไทยแม้ Minecraft ตั้งเป็นภาษาอังกฤษ รวมตัวแก้ Singleplayer และ Advanced Fake Players จากรุ่นก่อน

- [รายละเอียดภาษาไทย](THAI_ONLY_0_6_3_TH.md)
- [คู่มือ Passive](PASSIVES_TH.md)
- [ทดสอบด้วย bot](FAKE_PLAYER_TEST_TH.md)
- [Dependency และการย้าย](MIGRATION_1_21_1_TH.md)
- [จุดเชื่อมต่อเอฟเฟกต์](PASSIVE_EFFECTS.md)

ผ่าน unit tests 16 และ GameTest 39 รายการพร้อม Advanced Fake Players กับ Carry On ตรวจ Singleplayer ด้วยม็อด DRC ทั้งชุดถึงหน้า Create World ได้

งานชื่อเล่นเซิร์ฟเวอร์พักไว้ก่อน ชื่อเป้าหมายในเมนูหุ่นและข้อความยังใช้ระบบเดิม DRC ที่ตรวจยังขาด Iron’s, Iron’s Lib และ GeckoLib สำหรับฟื้นมานา
